
# Flappy Bird

**Team:** Alexander Engelhardt (313291)
**Repository:** [Link zum Repository](https://github.com/Guakocius/htwg/tree/main/sem5/webapp)

## Projektidee

Dieses Projekt wird in den kommenden Wochen *Flappy Bird*, ein "Casual Mobile Game", 
als Web-Applikation implementieren. Dort wird es ein Register/Login-System geben, bei
dem man ein Konto registriert, welches in einer Datenbank gespeichert wird und in einem
Leaderboard geordnet. Dieses Spiel ist für alle Alter- und Berufsgruppen ein absolutes
Erlebnis.
